write an algorithm to read from ADC0, Aref= Avcc, prescalar 64, store the value?


Globally enable

ADMUX
ADCSRA

SET ADMUX ADC INPUT PIN I.E ADC0 0000
SET VOLTAGE REFERENCE REFS1, REFS0 TO O, 1 (AVCC with external capacitor at AREF pin)
SET  ADPS0 ADPS1 ADPS2 TO 0,1,1 FOR 64 DIVISION FACTOR.

SET ADEN TO 1 IN ADCSRA TO START THE CONVERSION.

TO CHECK CONVERSION HAS STOPPED, CHECK ADIF FLAG IS SET, IF FLAG IS SET, SET ADIE AND SREG TO EXECUTE COMPLETE CONVERSION INTERRUPT.

THE CONVERTED DATA IS AT ADCL AND ADCH.

RESET THE ADIF BY WRITING A SET BIT 1.
